# VideoReferee Solo

One referee, one phone, no setup.

Film a bout. Hit **BOOKMARK** when you see something worth a second look — up to
five times, and it keeps filming. When the fight is stopped, hit **STOP** and
every mark is there to look at: the second and a half before it and the second
after, steppable a frame at a time.

Then it is thrown away and the next bout starts.

**Nothing is stored and nothing is uploaded.** The footage never leaves the
phone — there is no account, no server and no network call after the page has
loaded. This films people, often children, at a public event, and a tool that
provably keeps nothing is one nobody has to have a conversation about.

## Using it

Open **https://martinfrancu.github.io/VRL/**, allow the camera, then **Share →
Add to Home Screen**. Open it from that icon and it runs full screen, with no
browser chrome — and after that first load it works with no signal at all.

## Where this came from

The sibling of [VideoReferee](https://github.com/MartinFrancu/VideoReferee),
which does the same job with several phones and a laptop, and is worth the setup
when several angles matter. This one is for when setting four phones up was
never going to happen.

It is a prototype. It offers four different ways of looking at a marked moment —
loop, scrub, step and shuttle — because nobody knows yet which one a referee
reaches for under pressure, and that is a question for a sports hall rather than
a desk.
